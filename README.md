# 재형 (coffee)의 자기소개 페이지

언더독 웹 기초 챌린지에서 HTML과 CSS로 만드는 반응형 자기소개 웹페이지입니다.

## 자기소개

- 이름: 박재형
- 학과·학번: 컴퓨터소프트웨어 22학번
- 닉네임: coffee
- 한 줄 소개: Veni, vidi, vici
- 관심사: 학습공학, 기타 치기, 헬스
- GitHub: https://github.com/coffee0708091

## 지원 동기

지난 학기 언더독 활동을 통해 웹 개발이 오늘날 갖춰야 할 중요한 역량 중 하나라고 느꼈습니다. 이번 학기에도 활동을 이어가며 웹 개발 환경을 더 깊이 이해하고, 직접 구현하는 능력을 키우고자 지원했습니다.

## 배우고 싶은 것

HTML과 CSS의 기본기를 다지고, 반응형 웹페이지 제작부터 배포까지의 과정을 익히고 싶습니다.

## 사용 기술과 페이지 구성

- HTML: 소개, 지원 동기, 관심사, 학습 목표, 만든 사람 정보
- CSS: 색상과 여백, 글꼴, Flexbox 배치, 미디어 쿼리, 관심사 카드의 hover 효과
- 상단 박스형 목차를 누르면 해당 구역으로 부드럽게 이동합니다.
- 화면 너비가 600px 이하이면 관심사 목록을 세로로 배치합니다.
- 프로필 이미지는 현재 표시하지 않습니다. `images/profile.svg`는 초기 임시 이미지로 보관합니다.

## 실행 방법

저장소를 내려받은 뒤 `index.html`을 웹 브라우저에서 엽니다. 별도 설치나 빌드 과정은 없습니다.
